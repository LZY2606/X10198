# 相位织图（Phase Weave）

离线的家系基因型 / 单倍型分相审阅应用。纯本地运行，不上传任何数据，
也不查询外部参考库。技术栈：Rust + Axum + SQLite（`rusqlite` 静态绑定）。

## 运行

```sh
cargo build --all-targets
cargo test --all-targets
cargo run -- --addr 127.0.0.1:5258
```

打开 http://127.0.0.1:5258 即可看到「相位织图」页面。数据库默认写到
`phase-weave.db`，可用 `--db <path>` 覆盖（`:memory:` 为内存库）。

## 数据模型与版本

- 样本只用本地匿名标识（`S-xxxx`），页面不展示任何外部身份。
- 导入内容：样本、亲缘关系、变异位置、基因型似然（GL，概率或 phred 均可）、
  读段连接（read link）、来源批次。每次 `POST /api/import` 生成一个新的
  输入版本；原始观测只追加、不覆盖，历史版本保留。
- 裁定（接受候选 / 锁定局部相位 / 关系标记为待确认 / 撤回 read link）以
  事件形式追加到分支，支持回退与开分支。

## 相位算法

1. GL 归一化后做 MAP 判型；空 GL 为缺失，杂合质量低于 20 隔离为
   「低质量杂合」证据。
2. 逐位点检查每个 trio 的 Mendelian 一致性；不一致不删行，而是隔离成冲突，
   并枚举**使约束恢复一致的最小观测集合**（暴力枚举所有子集，按质量排序，
   给出全部等小集合）。孩子的等位在父母双方都不存在时标 de novo 候选。
3. 相位证据来自父母→子女传递（父亲纯合时确定父源等位）与 read link。
   按染色体构建连通分量（phase block）；跨越已独立导出分量的 read link
   记为**桥接证据**。撤回桥接 read link 后只有受影响区域拆回两个 block。
4. 每个 block 枚举候选（首位点方向固定，消除父源/母源整体互换的等价类），
   按满足证据的权重打分，**全部并列最高分候选都保留**，并列出每个候选
   支持的观测、权重与被忽略的数据。
5. 候选预算 `CANDIDATE_BUDGET = 64`。精确枚举空间 ≤64 时穷举；超出后改为
   beam search 并把 `budget_hit` 透出，页面明确提示「不保证唯一解」。

## 并发控制与重放

- 每条裁定携带 `expected_version`，与当前输入版本不符时返回 `409`，
  防止基于旧版本的并发裁定被静默接受。
- `GET /api/export` 导出钉住的输入版本、批次清单与裁定事件；
  `POST /api/replay` 在空库上逐步重放，重启后可完整复原审阅状态。

## HTTP 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` | 审阅页面（家系图 / 变异矩阵 / block / 冲突） |
| GET | `/api/state?branch=main` | 全量审阅视图 |
| POST | `/api/import` | 导入新批次，返回新输入版本 |
| POST | `/api/decide` | 接受候选 / 锁定相位 / 关系待确认 |
| POST | `/api/links/{id}/retract` | 撤回一条 read link |
| POST | `/api/rollback` | 回退分支最后一条裁定 |
| POST | `/api/fork` | 从某分支（指定 seq）开新分支 |
| GET | `/api/export` | 导出钉住版本与事件 |
| POST | `/api/replay` | 在新库上重放 |

## 测试覆盖

合成小家系覆盖：父源/母源互换等价、三等位错误的最小隔离集、缺失基因型、
de novo、并列候选、桥接撤回只拆受影响区域、关系修订与回退、旧版本并发
裁定拒绝、候选预算命中不伪装唯一解、锁定相位、导出重放、重复样本。
